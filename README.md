# 数学4択クイズ

YouTubeのコミュニティ投稿のような見た目で、数学の4択問題を解けるWebアプリです。
スマホ・iPadのブラウザで動き、インストールは不要です。

## できること
- みんなの回答の割合、問題の投稿（Firebase 設定後）
- 通算・最近100問・単元ごとの正答率
- 選択肢をタップすると、その場で正解・不正解を判定し、解説を表示
- 単元ごとの絞り込み、「まちがえた問題」「まだ解いていない」だけを表示
- シャッフル出題、「もう一度解く」
- 回答記録は端末（ブラウザ）に保存（正解数・各問題の正答回数）
- ダークモード対応

## 使い方
`index.html` を開くだけで動きます。生徒と共有して、みんなの回答の割合・問題の投稿まで使うには
**[SETUP.md](SETUP.md)** の手順で GitHub Pages と Firebase（どちらも無料）を設定してください。
生徒は URL を開くだけで使え、アカウント登録は不要です。

- `index.html` / `app.js`：アプリ本体
- `firebase-config.js`：Firebase の設定（未設定でも「この端末だけ」のモードで動きます）
- `firestore.rules`：Firebase に貼り付けるセキュリティルール
- `questions.js`：サンプル問題（先生が最初に登録する12問）

## 問題の追加・編集
`questions.js` を編集します。1問はこの形です。

```js
{
  category: "2次関数",
  question: "y = 2x² − 8x + 5 の頂点の座標は？",
  choices: ["(2, −3)", "(−2, 29)", "(4, 5)", "(2, 5)"],
  answer: 1,            // 正解の番号（1〜4）
  explanation: "y = 2(x − 2)² − 3 より、頂点は (2, −3) です。"
},
```

## みんなで使う版（app/quiz.html）
claude.ai のアーティファクトとして公開している版です。
みんなの回答割合、自分の通算／最近100問／単元ごとの正答率、参加者による問題投稿に対応しています。
データは claude.ai 側のデータベースに保存されます（先生の問題は `posts/official`、各自の投稿は `posts/<id>`、
最初の回答は `answers/<id>`、個人の成績は本人だけが見られる `data/users/<id>/stats`）。
